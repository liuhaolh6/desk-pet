# 用户手册

小芳是一只住在桌面上的宠物：点一下会说话，会提醒你喝水，也能换成你自己的照片。
这份手册写给第一次用的人——按顺序看一遍大概三分钟，遇到问题直接跳到「常见问题」。

---

## 三分钟上手

1. **先把它装上**：下载 `DeskPet-<版本>-setup.exe`，双击一路“下一步”（装在自己账户下，不需要管理员）；不想安装就用 `portable.exe`，双击即用。
2. **点它一下**：依次弹出天气 → 喝水 → 温馨语句，走完再点就收起来。
3. **选个城市**：鼠标停在它身上，点右上角的 **☰ → 设置 → 天气**，搜一个城市存下来。不选也能跑，只是天气显示「还没取过天气」。
4. **摆到顺手的位置**：直接拖着它走，松手会轻轻吸附到屏幕边缘。位置和大小都记在设置里。

第一次打开会弹一张三步欢迎卡，点「知道啦」以后不再自动出现。
想重看：**设置 → 其他 → 再看一次欢迎引导**。

## 常见问题

### 1. 桌宠不见了，托盘图标也找不到它

按 **Ctrl+Alt+P**：显示它，再按一下收起来。这是给它留的后路。
只要桌宠还在桌面上，把鼠标移到它身上就会浮出 **☰** 菜单，设置和退出都在里面。

托盘是不是真的坏了，可以去 **设置 → 其他 → 托盘和快捷键** 看结论：那一行会写清楚「托盘没问题」还是「这次没显示出来」，以及 Ctrl+Alt+P 有没有注册成功（被别的软件占用时会写原因）。

### 2. 天气不对，或者一直显示「离线缓存」

- 打开 **设置 → 天气**，重新搜城市并保存。
- 「离线缓存」表示这次没连上 Open-Meteo，显示的是上一次成功取到的数据，不是故障。
- 天气默认 15 分钟刷新一次；想立刻刷新：**☰ → 看看天气**。
- 想让它安静一会儿：**设置 → 外观 → 模式** 切到「安静」，提醒和主动气泡都会变少。

### 3. 气泡里的字太小 / 太长看不清

气泡会先换行，放不下时按比例缩小；**最多缩到原字号的 60%**（这是 0.6.6 起的下限，以前会一路缩到糊成一团）。
如果缩到 60% 还是放不下，超出的部分会截断成 `…`，完整文字仍保留在这一行的 `title` 和屏幕阅读器用的 `aria-label` 里。

- 想改字号、加粗、颜色：**☰ → 布置气泡**，选中模块后右侧有样式面板。
- 想少写点字：编辑器里把长句拆成两三行，或换成更短的模块。

### 4. 喝水提醒不弹

按顺序排查：

1. **设置 → 喝水**：间隔是不是设得太长（默认 60 分钟）？
2. 免打扰时段（默认 23:00–08:00）里不会弹，也不会计数。
3. **模式** 是「安静」时，提醒会被压到很低。
4. 桌宠窗口被隐藏时，提醒走 **Windows 系统通知**；如果系统通知被关掉（设置 → 系统 → 通知），就什么也看不到。

想看今天喝了几杯：点它一下，喝水那张卡上有进度。

### 5. 怎么换成自己的照片

**☰ → 设置 → 角色 → 用照片做个我**：

1. 选一张正面、背景干净的照片（半身或全身都行）。
2. 等它离线抠图（U2Net 模型随应用打包，不联网）。
3. 抠完可以擦除、恢复、旋转、翻转、缩放，满意了点保存。
4. 存成角色后，在角色图库里点一下就切换。

抠不出人像时不会假装成功，会退回「仅缩放导入」——直接把你选的整张图当角色。
照片只存在本机 `roles/` 目录里，不上传。

### 6. 我的设置和数据到底存在哪？怎么备份

**设置 → 其他 → 打开文件夹**，会打开数据目录：

| 内容 | 说明 |
|---|---|
| `settings.json` | 名字、大小、位置、天气/喝水/气泡/音效配置 |
| `roles/` | 导入的角色图和抠图结果 |
| `sounds/` | 导入的音效片段 |
| `weather.json` | 上次取到的天气缓存 |
| `app.log` | 运行日志，出问题时最有用的那部分 |
| `diagnostics-*.txt` | 你手动导出的诊断信息 |

便携版默认写在 exe 同级的 `desk-pet-data\`；安装版在 `%APPDATA%\desk-pet\`（以界面里显示的路径为准）。整目录复制走就是备份，搬到另一台机器同名目录下就能接着用。

### 7. 开机自启、鼠标穿透、大小和位置

- **开机自启**：设置 → 其他（便携版会随 exe 位置走，移动文件夹后请重设一次）。
- **鼠标穿透**：桌宠窗口只有在光标真正落在它或气泡上时才接鼠标，其余时间点得到底下的窗口，这是刻意的。
- **大小**：设置 → 外观 → 多大一只，120–360px，拖动即时生效，脚底位置不动。
- **位置**：直接拖，或者 设置 → 外观 → 回到右下角。
- **始终置顶**：默认开；关掉后它会被别的窗口盖住。

### 8. 出问题了，怎么把信息发出来

**设置 → 其他 → 遇到问题 → 导出诊断信息**，会在数据目录写一个 `diagnostics-年月日-时分秒.txt` 并自动打开文件夹。

里面是：版本、Electron/系统信息、屏幕布局、托盘与快捷键状态、日志尾巴。
**已经脱敏**：城市名和经纬度打码成 `[已脱敏]`，自定义短语不导出，也不会带上任何照片。

把它和「当时在做什么 + 期望看到什么」一起发到 [Issues](https://github.com/liuhaolh6/desk-pet/issues) 就够了。

### 9. 怎么彻底卸载

- **安装版**：先在桌宠里 **设置 → 其他 → 先退出啦**，然后去 Windows「设置 → 应用 → 已安装的应用」搜“桌宠”点卸载（也可以在开始菜单的桌宠文件夹里点“卸载”）。卸载只删程序，`%APPDATA%\desk-pet\` 里的数据会留着。
- **便携版**：退出后直接删掉 exe 和同级的 `desk-pet-data\` 文件夹。
- 最后按需删数据目录（见第 6 条）；如果开过开机自启，在 **设置 → 其他** 关掉，或去「任务管理器 → 启动」里禁用。

## 键盘与无障碍

- 欢迎卡默认焦点在「知道啦」，**Esc** 直接关。
- 设置页、编辑器全部可用 **Tab** 遍历，焦点有可见描边。
- **Ctrl+Alt+P**：显示 / 隐藏桌宠（全局，任何窗口在前台都有效）。
- 系统开启了「减少动态效果」时，界面会关掉过渡，不影响功能。

## 数据与隐私

- 不需要账号，不上传任何东西。
- 只请求一个外部接口：[Open-Meteo](https://open-meteo.com/)（天气与城市搜索），不带账号信息。
- 城市坐标只写在本机 settings 里，导出诊断时会被打码。
- 抠图在本地跑，照片不出本机。
- 更新只比版本号，不会偷偷安装；不想让它查，去「其他 → 更新」关掉。
- 完整清单（存了什么、发到哪、怎么删）见 [数据与隐私](PRIVACY.md)；设置页「其他 → 数据与隐私」里有一键清理日志和缓存。
