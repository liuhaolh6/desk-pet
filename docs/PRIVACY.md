# 数据与隐私

一句话：**桌宠不联网也能用；联网只去三个地方，且都由你触发或可预期。**

这份文档描述的是 0.6.9 的实际情况，不是“计划”。设置页「其他 → 数据与隐私」里显示的数字，是从磁盘实测来的，和这里一致。

---

## 一、东西存在哪

全部在设置页「东西放哪」那一行显示的目录里（默认在 `%APPDATA%\desk-pet\data`，便携版在 exe 旁边的 `data`，可用 `DESKPET_DATA_DIR` 覆盖）：

| 文件/目录 | 里面是什么 | 删了会怎样 |
|---|---|---|
| `settings.json` | 城市、昵称、气泡文案、提醒开关、窗口位置等 | 会重置成默认值 |
| `roles/` | 你自己加的角色图 | 自定义角色消失，自带角色仍在 |
| `photos/` | 「用照片做个我」抠好的图 | 那张角色图没了 |
| `sounds/` | 你导入的提示音 | 需要重新导入 |
| `app.log` | 运行日志（每次启动追加，单文件上限 1 MB） | 不影响使用，只是以后查问题少线索 |
| `cutout-trace.jsonl` | 抠图过程记录（输入尺寸、耗时、失败原因） | 同上 |
| `Cache/`、`Code Cache/`、`GPUCache/` 等 | Chromium 的缓存 | 下次启动会重建 |
| `water.json` | 喝水记录（日期、杯数） | 喝水统计清空 |

「清理日志和缓存」按钮只删上表里的 **`app.log`、`cutout-trace.jsonl` 和各个缓存目录**。设置、角色图、照片、声音、喝水记录**不在清理范围内**——它们是你的数据，要删请自己删对应文件。

## 二、什么会发到网络上

| 什么时候 | 发到哪 | 发了什么 | 能不能关 |
|---|---|---|---|
| 换城市（点城市名 / 设置里改） | `https://geocoding-api.open-meteo.com` | **城市名**，换回经纬度 | 能：手动填经纬度（`settings.weather.lat/lon`） |
| 刷新天气（默认每 30 分钟，点公告栏也会刷） | `https://api.open-meteo.com` | 经纬度、固定参数 | 能：把天气模块从公告栏删掉，或断网用缓存 |
| 公告栏里有空气模块时 | `https://air-quality-api.open-meteo.com` | 经纬度 | 能：删掉空气模块 |
| 检查更新（启动后一次，之后每 24 小时） | `https://raw.githubusercontent.com/.../update.json` | 只有一个 GET，不带任何标识 | 能：设置 → 其他 → 关掉「启动时自动看一眼」 |
| 你点「去下载」 | `https://github.com/.../releases` | 用系统浏览器打开，桌宠不参与 | 不点就不发 |

除此之外：

- **没有账号、没有登录、没有埋点、没有崩溃上报。**
- **照片和角色图不会上传。** 抠图用的是随安装包一起下发的本地模型（`models/`），全程在本机 CPU 上跑。
- 「导出诊断信息」是你主动点的：它会写一个 txt 到数据目录，里面**城市名和经纬度已打码**，只有日志尾部、版本、系统信息，**不包含任何照片**。
- 更新检查只比较版本号字符串，不会下载或执行任何东西（未签名版本不做静默安装，见下方说明）。

## 三、几个你可能会担心的点

**它会偷看屏幕吗？**
不会。它只知道自己窗口的位置，不截屏、不读别的窗口内容。唯一的例外是你主动打开「用照片做个我」并选了图片——那张图由你指定。

**它会偷偷装东西吗？**
不会。0.6.9 的更新提示只做三件事：查版本号、在气泡里说一声、在你点「去下载」时打开浏览器。真正的静默安装要等产物有代码签名之后才会开（见 `M6-PACKAGING.md`），当前版本 `settings.update.installUpdates` 默认为 `false`。

**开机自启是什么？**
写的是注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下一条 `DeskPet`，指向上面的可执行文件。设置里关掉就会删掉这条。

**卸载会留下什么？**
安装版卸载会删掉程序目录和开始菜单快捷方式；数据目录（`%APPDATA%\desk-pet\data`）**默认保留**，方便你重装后接着用。想彻底清干净，卸载后手动删掉那个目录即可。
